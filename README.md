# pt
## Cairo Prayer Times
## Calculated using Egyptian Survey Authority

This is a simple command line app to satisfy personal need, a simple utility to give prayer times in my hometown for same day.

However, flags are avaialble to enter different date, timezone, or lat & long

So, default is **Cairo, Today** , or you may:
pt -- --lat 29.9097 --lon 31.1563 --tz 2 --date 2026-03-20
